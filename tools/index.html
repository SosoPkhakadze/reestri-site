Try a public-register lookup

Search Georgia or Armenia without an account. This returns public-register data, not an official ordered extract. For Georgia, an exact 9-digit company code is often the clearest search.

Up to six queries per IP per hour. Results may be cached for up to six hours. Do not enter confidential matter details.

One request, structured evidence

Use your own Apify token in your application or agent. The public site never asks for your token.

HTTP request

curl -X POST   "https://api.apify.com/v2/acts/reestri~ge-company-lookup/run-sync-get-dataset-items"   -H "Authorization: Bearer $APIFY_TOKEN"   -H "Content-Type: application/json"   -d '{"query":"Silknet"}'

Know the source and its limits

Georgia companies and participants

Public NAPR lookup and participant search. Gated documents are outside the automated tool.

Live source

Armenia companies

Company cards and available public beneficial-owner declarations. Declaration coverage is partial.

Live source

Armenia public contracts

An indexed procurement dataset. Check registryAsOf in each result; an index is not a live portal.

Indexed

Moldova

State open-data index, opt-in pending clarification of reuse terms. Check source dates.

Opt-in

Unavailable sources

Missing declarations, source failures and no-match results must be reviewed rather than treated as proof.

Explicit limits

Sources have different coverage and refresh schedules. Review the source URL, retrieval time, any snapshot date and current listing before relying on a result.
