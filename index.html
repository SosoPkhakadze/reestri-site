The ledger

Five tools, three registers, one record shape

Both registers publish in non‑Latin scripts through card‑by‑card portals. Reestri reads the open surfaces and returns normalised English JSON. Select a row to see a real record, fetched live from the register.

Moldova ships as an opt‑in inside the screen while the register’s re‑use terms are confirmed in writing with ASP. Kazakhstan and Azerbaijan are researched and parked; their portals block programmatic access.

Method

Rules the tools never break

  • Official sources onlyNAPR, e‑register.moj.am, armeps.am, dataset.gov.md. Open surfaces; no captcha bypass, no login walls, no robots‑excluded paths. Georgia’s gated ownership extracts stay gated; we say so instead of pretending.
  • Evidence on every recordSource URL, retrieval timestamp and SHA‑256 of the fetched content, so a compliance file or an article can cite and re‑verify the exact observation.
  • No personal identifiersBeneficial owners are named as the state publishes them; personal ID numbers and home addresses are never returned.
  • Honest failureRegistry down or changed? The run fails loudly and the record says unavailable. Daily green‑run checks keep the public success stats real.
